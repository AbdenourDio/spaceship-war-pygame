# 🚀 Spaceship War

A simple 2-player local shooting game built with Python and pygame-ce.

## 🎮 Gameplay

Two players control spaceships and try to shoot each other using the same keyboard.

### Controls

Player 1:
- Move: Q Z S D  
- Shoot: Left CTRL  

Player 2:
- Move: Arrow keys  
- Shoot: Right CTRL  

## ✨ Features

- Local 2-player gameplay  
- Spaceship movement and shooting  
- Collision detection  
- Simple scoring system  
- Built with pygame-ce
